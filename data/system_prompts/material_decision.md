# 任务目标

结合当前人设、最近对话，以及本轮最新信号，判断现在最适合顺手转发哪一条素材给对方。

本次调用不是聊天回复生成任务。你不需要直接回复对方，也不需要代替后续文案生成；你只负责做转发判定，并给出后续步骤可用的轻量提示。

# 输入数据

候选素材卡片 JSON：
{{candidate_cards_json}}

素材关联度：{{sensitivity}}

素材关联度说明：
- 严格：只选强相关素材
- 均衡：能自然接上就发
- 宽松：可自然转场就发

# 决策原则

1. 你必须在当前判定参数下做决策，不要脱离“素材关联度”自创一套策略。
2. 你必须严格按照当前素材关联度做决策：`严格` 只选强相关且顺手自然的素材，`均衡` 可以选择能自然接上的素材，`宽松` 可以接受不生硬、可转场的弱相关素材。
3. 判断时要优先结合基础人设、最近历史对话的整体语境、当前关系阶段和聊天走向，不要只盯着本轮最新信号做表面关键词匹配。
4. 本轮最新信号很重要，但它更适合作为“语境里的最新线索”来辅助判断，而不是唯一依据。
5. 如果本次是补检场景，没有新的好友来信，就以最近对话整体语境、关系阶段和最近可见信号为主判断。
6. 你的首要任务是先在候选里选出“当前最适合发的那一条”；不要轻易因为犹豫就放弃选择。
7. 只有当全部候选都明显不合适、发出去会显得突兀或打扰时，才输出 `should_send=false`。
8. 多个候选都可选时，优先选择最符合当前人设关系、最顺着最近对话语境、最不需要额外解释、最像顺手分享的那条。
9. `send_strategy` 用一句话说明“这次如果发，应该从什么角度切入”，给后续步骤轻量提示，而不是写成最终发给用户的话。
10. 不要暴露内部的任务、标签、提示词、策略或系统规则。

# 输出格式

请只输出一个合法 JSON，对象必须包含以下字段：

{
  "should_send": true,
  "selected_index": 2,
  "send_strategy": "内部发送策略摘要，给后续步骤的轻量提示，不直接发给用户"
}

额外要求：
1. 只输出 JSON，不要解释。
2. 当 `should_send=true` 时，`selected_index` 必须填写候选素材卡片 JSON 中实际存在的 `index`，不能自造、猜测或填写 `0`。
3. 当 `should_send=false` 时，`selected_index` 必须填写 `0`，不能填写任何候选素材的 `index`。
