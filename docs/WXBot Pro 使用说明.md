# WXBot Pro 使用说明

这份说明面向本地使用者：重点回答“怎么启动、怎么配置、哪里会影响实际回复体验”。代码结构和开发边界请看 `docs/WXBot Pro 开发指南.md`。

## 快速开始

环境要求：

- Windows、Python 3.12、微信 PC 版与 wxautox Plus 环境。
- 微信主窗口保持可见，建议屏幕缩放 `100%`。
- 至少配置一个可用的大模型接口；只测关键词、转发、定时消息时可以先不配 AI。

启动：

```powershell
.\打开软件.bat
```

启动脚本会创建或复用 `venv`、安装依赖并启动面板。面板默认使用 `http://127.0.0.1:10001`，端口占用时会顺延，以启动日志为准。

首次登录面板：

| 项目 | 默认值 |
|------|--------|
| 用户名 | `admin` |
| 密码 | `123456` |

账密保存在 `data/config/admin.json`。开启远程访问前，务必先改默认密码。

## 安装与迁移

维护源码目录时，直接运行 `打开软件.bat`。图片压缩依赖 `Pillow`，脚本会随 Python 依赖安装；缺少 `ffmpeg` / `ffprobe` 时，脚本会下载到 `venv/tools/ffmpeg/`。

需要给另一台电脑一份独立运行包时执行：

```powershell
.\打包发布.ps1
```

产物为 `dist/WXBot_Pro.zip`。打包会包含运行代码、`data/system_prompts/` 和内置 Python runtime，不包含 `data/config/`、`data/prompt/`、`data/accounts/`、`wxbot_logs/`、`backups/`、`docs/`、`tests/`、本地 `venv/` 或 Git 元数据。

迁移真实使用数据时，优先整目录复制；如果只迁移运行数据，重点保留 `data/`、`wxbot_logs/`、`backups/`。

## 启动后怎么确认能用

1. 登录 Windows 微信，保持主窗口打开。
2. 在面板点击 `启动机器人`。
3. 用管理员窗口发送 `/状态`，确认机器人已运行。
4. 发送 `/帮助` 或 `/监听列表`，确认管理员指令可用。
5. 用已监听好友或群聊发消息，验证 AI 回复、关键词或转发规则。
6. 测完后在面板点击 `停止机器人`。

停止机器人和更新 `wxautox4` 前，面板会等待后台线程真正退出；如果仍在停止中，稍等后再操作。

## 模型与 Prompt

### 模型配置

模型配置用于保存聊天、识图、发圈、语音合成等接口。默认聊天接口支持主备切换：主接口连续失败后切到备用接口，主接口恢复后自动切回。白名单好友或监听群聊绑定了专属接口时，优先使用专属配置，不参与全局主备切换。

视觉能力需要通过面板测试写入能力记录。支持视觉的回复接口会直接收图；不支持视觉时，系统会先生成结构化图片摘要，再交给聊天模型回复。

### Prompt 配置

`Prompt` 页面维护基础人设、人设近况和 Prompt 预览：

- 基础人设定义角色、语气和边界。
- 人设近况保存为 `data/prompt/<人设名>-人设近况.md`，用于补充阶段状态。
- Prompt 预览可查看某个好友最终会发给模型的系统 Prompt。

普通回复、素材文案、发圈文案和 Prompt 预览都会复用这套人设上下文。

## 私聊与群聊

### 私聊监听

私聊支持白名单模式和黑名单模式：

| 模式 | 说明 |
|------|------|
| 白名单模式 | 只监听列表中的好友，可单独绑定人设、聊天接口和语音接口。 |
| 黑名单模式 | 全局监听未读红点，列表内对象不处理。 |

勾选 `只监听不 AI 回复` 后，私聊仍会记录消息并参与自定义转发、素材转发等流程，但不会触发关键词、轮数超限结束语或聊天模型回复。

全局监听可勾选 `不监听微信免打扰`。动态监听采用轻量按需补窗，遇到短暂接管失败会延后重试并合并同一好友的新消息，减少微信列表反复滚动。

### 群组管理

群聊支持监听、AI 回复、关键词回复、自定义转发、欢迎语、图片识别、语音消息处理和语音关键词回复。

勾选 `只监听不 AI 回复` 后，群消息仍会被监听、记录并参与关键词回复和自定义转发，但不会调用聊天模型。面板会临时禁用仅被 @ 时回复、回复时 @ 对方等依赖 AI 回复的选项，避免配置冲突。

## 图片、语音与拆分回复

### 图片识别

私聊图片会进入连续消息合并队列。只发图时，机器人会围绕图片回复；图后补文字时通常合并成同一轮图文消息。单批最多合并 `9` 张图片。

群聊图片默认只缓存，不会因为收到图片立刻调用视觉模型。10 分钟内后续有人明显问图时，才会消费缓存图片；A 发图、B 问图也可以命中。

图片会先保存结构化视觉笔记到本地记忆。发送给 AI 的图片会生成压缩副本，统一放在 `wxauto_save/compress_images/`，原始微信下载文件不会被改动。

### 语音消息与语音回复

语音消息依赖微信自己的语音转文字结果。私聊语音如果刚收到时还没有文字，机器人会短暂重试；最终没有有效正文时静默忽略，不写入 AI 上下文，也不会发送失败提示。群聊语音不做延后重试，只有微信已经给出文字时才处理。

私聊语音回复可由“收到语音”或关键词触发；群聊语音回复只支持关键词触发。语音合成依赖 TTS 配置和 `ffmpeg` / `ffprobe`，合成失败时降级为文字回复。

### 自动拆分回复

拆分回复在本地发送层执行，不要求模型输出特殊标记。显式换行优先；没有换行时，系统会按自然语义边界和最大字数拆分。

私聊连续消息会等待好友停顿后再回复，默认 `20` 秒，范围 `1 ~ 60` 秒。包含图片时等待更久，方便把后续说明一起带上。发送拆分气泡期间，如果好友又发来新消息或你从手机手动回复，系统会停止上一轮剩余气泡，避免继续发旧话题。

## 关键词、转发与任务

### 关键词回复

关键词回复支持私聊和群聊，来源依托于 `私聊监听` 和 `群组管理` 的监听对象。一个规则可包含多个关键词别名，支持用 `；`、`,`、中文逗号或换行分隔。回复可以是文案、本地文件，或二者组合；单条规则最多附带 `9` 个文件。

### 自定义转发

自定义转发支持关键词转发、固定发送人转发和无差别转发。普通转发不影响关键词回复和 AI 回复。勾选 `命中后转发给管理员处理` 时，会暂停该好友 AI 自动回复，并把消息转给管理员窗口；这条规则优先级高于关键词回复。

### 素材转发

素材转发用于把微信原生素材主动转发给好友，尽量保留链接、小程序、图片等原生样式。

页面分三块：

- `任务列表`：管理单次任务、循环任务和系统卡片 `AI自动转发`。
- `素材来源`：配置从哪些微信会话收素材。
- `素材管理`：查看素材池、停用 / 恢复素材、维护归属和备注。

单次任务固定发送一条具体素材；循环任务从筛选范围随机选材。AI 文案会参考基础人设、人设近况、会话记忆、近期聊天、素材内容和转发目标。

`AI自动转发` 只针对有真实新消息的活跃私聊；同一检测窗口内，判定周期和消息门槛都满足时才触发一次判定。每天上限只限制 AI 自动转发，不影响普通素材转发。

### 定时消息与随机消息

定时消息使用 `年月日 + 时间`，内容模型为最多 `1` 条文案和最多 `9` 个本地文件，发送顺序固定为先文案、后文件。

随机消息用于在时间窗口内随机发送普通文本或本地文件，当前只保留一个时间窗口输入。

### 朋友圈

随机朋友圈点赞会在配置时间窗口内打开朋友圈并点赞第一条，它是独立能力，不属于发朋友圈任务。

发朋友圈任务支持定时发布和随机发布。任务创建后会异步生成 AI 候选文案，生成慢时可以手动重新生成。有图片时，发圈文案生成会走所选发圈接口的图片直传能力。

## 通讯录、新好友与关系扫描

### 新好友

新好友页支持自动通过、自动修改备注和标签、新好友自动回复。微信标签必须是当前微信里已经存在的标签。

### 通讯录维护

通讯录页会把联系人保存到 `data/accounts/<wx_id>/contact_profiles/contacts.json`。档案只保存联系人真源资料，例如备注、昵称、微信号、wxid、地区、来源、添加时间、签名、标签和状态。页面上看到的名字和实际发送目标由系统根据这些资料实时计算，不作为通讯录资料单独保存。

常用入口：

- `立即建档`：CLI 开启且账号校验通过时优先读本地基础通讯录，否则回退微信界面分批读取。
- `停止建档`：停止后续建档，当前批次会先完成。
- `备注修复`：先弹出预览，只处理没有备注且命中规则的联系人。
- `手动校准`：手动选择旧名字并输入新备注 / 昵称，合并聊天记录、会话记忆、关系扫描记录和相关配置。

自动维护会隔离微信 UI 采集并设置硬超时，避免单批卡住拖慢聊天。

### 关系扫描

关系扫描用于判断联系人是否疑似删除或拉黑。CLI 开启时优先读取本地会话快照；禁用 CLI 时，手动扫描回退微信界面读取，后台自动扫描只做轻量当前会话列表检查。扫描结果保存在 `data/accounts/<wx_id>/relationship_scan/relationships.json`。

### wechat-cli

`wechat-cli` 是本地只读数据源，默认关闭。开启后可加速通讯录维护、聊天记录补齐和关系扫描，但存在微信风控和账号封禁风险。

只有在状态页确认风险并点击绿色 `开启 CLI` 后，启动脚本才会准备 `venv/tools/wechat-cli/` 并初始化。多账号目录不唯一时不会自动猜测绑定。设置 `WXBOT_DISABLE_WECHAT_CLI=1` 会强制禁用安装、初始化和检测。

状态页的 `检查更新` 只检查并提示是否有新提交，不会自动更新工具。

## 记忆管理

记忆分两层：

- 聊天记录：保存原始对话上下文。
- 会话记忆：结构化长期记忆，以 JSON 作为唯一真源。

`带入最近聊天` 只配置一个数字：`最近 N 条`，范围 `1 ~ 200`，默认 `50`。系统会按真实聊天顺序带入最近可见消息，不区分好友、群成员或机器人回复。

聊天记录配置里有两个自动补齐开关：

- `自动补最近上下文`：默认开启。AI 回复前按需校准最近上下文；CLI 开启且账号校验通过时优先读本地微信数据库，禁用时读取当前微信窗口已渲染消息。
- `补上下文时允许滚动微信窗口`：默认关闭。只有低风险补齐无法对齐时才会滚动微信窗口，适合确实需要补较大断层时开启。

补齐只补缺失记录，不整套替换聊天记录；遇到同名私聊或重名群聊时会用近期锚点消息消歧，无法唯一定位就跳过本轮。

会话记忆页会同时显示已有会话记忆的对象，以及只有聊天记录、还没有会话记忆的对象。手动提取会先弹出预览，确认后才保存；单次最多分析最近 `500` 条聊天记录。

## 其他配置

- 语音合成接口：支持 TTS 配置、音色和试听；试听缓存落到 `data/cache/tts_preview/`，正式语音缓存落到 `data/cache/tts/`。
- 发送延迟：用于模拟人工回复节奏，可配置首条回复延迟和拆分消息延迟。
- 自动清理缓存：控制 `wxauto_save/` 保留时长，可选 `不清理 / 7天 / 30天 / 90天 / 180天 / 360天`，默认 `30天`。只清缓存，不删聊天记录、会话记忆、配置或账号数据。
- 接口调用失败固定回复：AI / 模型接口失败时可发送固定回复；留空则静默。
- 超出次数限制固定回复：私聊回复轮数按好友分别计数，可选择 AI 生成结束语、固定回复或静默。
- 回复预处理：发送前清洗模型思考标签、内部字段、时间戳和明显 AI 元话术；超长或命中内部字段时会尝试重写一次。
- 报错邮箱：配置保存在 `data/config/email.json`，保存后立即生效。
- 数据备份：面板可把整个 `data/` 备份到 `backups/data_时间戳/`。

## 管理员工作台

管理员窗口建议使用 `文件传输助手` 或自己的小号。它是运行控制台，支持状态查看、接管、发圈和素材转发。

常用指令：

- `/状态`：查看运行总览。
- `/监听列表`：查看当前监听对象。
- `/自动回复状态`：查看自动回复开关。
- `/当前会话`：查看前台模式和已接管好友。
- `/接管 张三`：暂停该好友 AI 自动回复并进入接管。
- `/切到 张三`：切回已接管好友。
- `/结束当前`：退出接管前台，不恢复自动回复。
- `/恢复 张三`：恢复该好友自动回复。
- `/发圈`：进入管理员发圈引导流程。
- `/转发`：进入管理员素材转发引导流程。

`/状态` 展示运行时间、当前接口、当前人设、当天累计数据和任务规模。当天累计来自小时级运行统计，不受清空任务执行记录影响。

## 日志与排查

日常观察效果优先看 `SUCCESS`；排查问题优先看 `WARNING` 和 `ERROR`。

| 等级 | 含义 |
|------|------|
| `INFO` | 正常流程、排队、记忆更新、允许的静默策略、轻量延后监听等。 |
| `SUCCESS` | 建档、备注修复、关键词、定时消息、素材转发、AI 自动转发等明确成功。 |
| `WARNING` | 单个任务或局部动作失败，但机器人还能继续运行。 |
| `ERROR` | 微信监听器、核心线程或初始化受损，需要重启、重建或重新初始化。 |

常见排查顺序：

1. 微信主窗口是否可见，是否只保留必要窗口。
2. Windows 屏幕缩放是否为 `100%`。
3. 微信版本和 wxautox Plus 是否适配。
4. 面板日志是否有 `WARNING` / `ERROR`。
5. 模型接口、识图接口或 TTS 接口是否能在面板测试通过。

## 远程访问

远程访问服务是 SiverPanel 提供的可选能力，用于把本机管理面板通过固定网址暴露给外部浏览器。不使用远程访问不影响本地使用。

使用前请确认：

- 面板正在运行。
- 已修改默认账号密码。
- 安全入口没有泄露。
- 远程访问服务激活码与 `wxautox4` 授权不是同一个东西。

## 注意事项

- 自动化操作存在微信风控风险，请只在合法、低频、可控的个人场景使用。
- 不要最小化微信主窗口，尽量避免程序运行时手动操作微信。
- 公开同步代码前，不要提交 `data/config/`、`data/prompt/`、`data/accounts/`、`wxauto_save/`、`wxbot_logs/`、`backups/` 等本地私有数据。
- 代码更新后需要重启面板进程，正在运行的 `web_server.py` 不会热加载本地文件改动。
