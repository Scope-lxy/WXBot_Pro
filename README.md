# WXBot Pro 自用增强版

面向 Windows 微信自动回复场景的个人维护 fork，覆盖私聊、群聊、图片、语音、关键词、素材运营、定时任务、好友自动化和通讯录维护。

维护原则：以当前代码和实际体验为准，不为旧任务、旧实例或旧记录额外保留兼容层。

## 文档入口

- `README.md`：总览、启动、目录边界和打包。
- `docs/WXBot Pro 使用说明.md`：面板配置和日常操作。
- `docs/WXBot Pro 开发指南.md`：运行链路、数据真源、改动边界和验证。
- `docs/消息处理流程图.html`、`docs/监听维护流程图.html`：消息处理与监听维护全景图，可直接用浏览器打开。
- `docs/WXBot Pro 设计规范.md`：面板 UI 规范。
- `docs/微信 UI 并发实测结果.md`：微信 UI 调度的实测结论和复验入口。
- `docs/微信 UI 主动轮询重构备选方案.md`：未来可实验的 owner 主动收消息方案；当前生产不启用。
- `docs/人设编写规范模板.md`：基础人设和人设近况模板。
- `AGENTS.md` / `CLAUDE.md`：给 AI 协作工具的项目规则，两份文件必须保持一致。

项目说明只维护根目录 Markdown 和 `docs/`；`data/` 下的 Markdown 是运行 Prompt，不属于项目文档。

## 快速启动

环境需要 Windows、微信 PC 版、wxautox Plus 环境和至少一个可用的大模型接口。

```powershell
.\打开软件.bat
```

脚本会用发布包内的 `runtime/python/` 创建或复用本机 `venv/`，安装依赖并启动面板；默认地址是 `http://127.0.0.1:10001`，端口被占用时自动顺延。缺少 `ffmpeg` / `ffprobe` 时，脚本会下载到 `venv/tools/ffmpeg/`。

真实运行链路：

```text
打开软件.bat -> web_server.py -> /start_bot -> wxbot_core.py
```

`web_server.py` 负责面板、配置、备份、接口测试和机器人启停；`wxbot_core.py` 负责编排监听、AI 回复和运营任务。所有真实微信动作均由唯一 UI owner 执行。

## 核心能力

- AI 回复：私聊、群聊、图片、语音、连续消息合并、会话记忆、拆分发送和主备接口切换。
- 关键词：私聊、群聊独立规则；可选首条文字引用原消息，群聊可 @ 发言人或仅在被 @ 时触发。
- 任务与素材：定时消息、随机消息、素材池、普通转发和 AI 自动转发。
- 通讯录与好友：建档、自动维护、备注修复、关系扫描、好友申请和标签同步。
- 安全投递：账号级 SQLite 保存消息事实、会话版本和投递边界；结果不明标为 `uncertain`，不会自动重发。
- 运行维护：全局未读扫描、按需补窗、可见尾部补洞、UI 卡死恢复和 wxautox4 版本提示。

详细操作看《WXBot Pro 使用说明》，改动代码前看《WXBot Pro 开发指南》。

## 重要目录

- `data/`：账号配置、Prompt、消息事实库、长期记忆、通讯录和任务真源。跨设备迁移时优先保留。
- `core/`、`feature/`、`extension/`、`templates/`：当前运行代码和面板资源。
- `runtime/python/`：随发布包携带的 Python 基础运行时；`runtime/` 其余文件只是运行期标记。
- `venv/`：本机依赖环境及项目级 `ffmpeg`，可由启动脚本重建。
- `wxbot_save/`：微信下载原件和 AI 图片压缩缓存，面板默认保留 30 天。
- `wxbot_logs/`：面板运行日志；`backups/`：面板一键备份产物。
- `tools/`、`tests/`：维护、复现和验证使用，不参与正式运行包。

不要提交 `data/config/`、`data/accounts/`、`wxbot_save/`、`wxbot_logs/` 或 `backups/` 等本地私有数据；`data/prompt/` 下只有 `模板.md` 和 `模板-人设近况.md` 纳入版本控制，其余人设和人设近况 Prompt 均为本机私有。

## 打包与迁移

继续维护源码时，直接复制整个项目目录最稳妥。

需要独立运行包时执行：

```powershell
.\打包发布.ps1
```

产物是 `dist/WXBot_Pro.zip`。它包含运行代码、`data/system_prompts/` 和 `runtime/python/`，不包含本机配置、账号数据、缓存、日志、备份、文档、测试、`venv/` 或 Git 元数据。

## 使用边界

- 微信主窗口需保持可见，不要最小化。
- 面板停止后，已经开始的微信动作会收尾；尚未进入微信的可恢复回复在 60 分钟内按当前规则重新处理。结果未知的动作不会补发。
- 生产环境不使用 `wechat-cli`、本地数据库旁路或 `msg.to_text()`。
- 这是个人自用 fork；更新代码后需要重启面板进程。

## 常见问题

**图片有时看不到？** 支持视觉的聊天接口会直接收图；其他接口使用本地生成的结构化图片笔记。

**语音转文字是否调用大模型？** 不会。它只使用微信已有的转写结果；没有可信正文时会静默跳过。

**PowerShell 中文乱码？** 通常是控制台显示编码问题，请用 UTF-8 读取文件，不要直接重写中文内容。
