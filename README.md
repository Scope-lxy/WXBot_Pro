# WXBot Pro 自用增强版

这是一个面向 Windows 微信自动回复场景的 WXBot Pro 自用维护版本，基于上游 `SiverWXBot Plus` 持续维护。它保留原项目的私聊、群聊、Prompt、记忆、转发和管理面板能力，并围绕人设陪伴、多接口配置、图片识别、会话记忆和回复体验做了定制增强。

这份仓库的维护口径很明确：优先当前实际使用体验与代码整洁，通常不为旧任务、旧实例、旧记录额外保留兼容层。

- 想通过 Web 面板维护微信自动回复机器人。

## 运行环境

- Windows
- Python 3.12
- 微信 PC 版与 wxautox Plus 环境
- 可用的大模型接口配置

## 快速启动

```powershell
.\打开软件.bat
```

启动脚本会自动创建或复用 `venv`、安装依赖并启动管理面板。开发时也可以手动运行 `venv\Scripts\python.exe web_server.py`。

如果系统里没有 `ffmpeg` / `ffprobe`，脚本会首次自动下载 Windows 预编译包到 `venv\tools\ffmpeg\`；如果系统 PATH 已经有可用版本，则直接复用。面板默认优先使用 `http://127.0.0.1:10001`，端口被占用时会顺延。

## 运行结构

当前真实启动链路是：

```text
打开软件.bat
-> web_server.py
-> /start_bot
-> 后台线程创建 WXBot
-> wxbot_core.py 主循环
```

可以把它简单理解成两层：

- `web_server.py` 负责面板、配置读写、页面 API、备份、接口测试和启动/停止机器人。
- `wxbot_core.py` 负责微信监听、AI 回复、任务扫描、素材转发、管理员接管和真实微信发送。

## 重点能力

- AI 回复：支持私聊 / 群聊、图片直传或两段式识图、语音转文字、语音回复、本地拆分回复、发送前清洗，以及默认聊天接口主备切换。
- Prompt 与人设：基础人设、人设近况、会话记忆和时间上下文统一组装，减少多处手工拼 Prompt。
- 管理员工作台：管理员窗口作为运行控制台，支持状态查看、接管、发圈和素材转发；状态面板和 `/状态` 会展示当天收发与 API 请求统计。
- 通讯录与新好友：支持手动建档、自动维护、备注修复、关系扫描、好友申请和标签同步。
- 任务系统：定时消息、素材转发、发朋友圈任务和朋友圈点赞共用统一调度模型，保存配置后可热同步后续任务。
- 会话记忆：以 JSON 为唯一真源，支持手动提取预览和后台增量维护。
- 素材转发：支持单次任务、循环任务、素材来源管理和 AI 自动转发。
- 监听维护：动态监听现在走轻量按需补窗，不再靠主循环高频巡检或残留窗口强清理来维持。
- 运行体验：停止机器人和更新 `wxautox4` 前会等待后台线程真正退出，减少“看起来停了其实没停”的问题。

具体页面怎么操作，请看 `docs/WXBot Pro 使用说明.md`。

## 重要目录

- `data/config/`：主配置、面板账号、邮箱、Webhook、回复轮数统计、当天运行统计等运行配置。
- `data/prompt/`：基础人设和人设近况文件。
- `data/system_prompts/`：系统级 Prompt 片段及其备份。
- `data/accounts/<wx_id>/`：聊天记录、会话记忆、通讯录、任务、发圈草稿等账号级数据。
- `core/`：底座能力，例如配置、Prompt、媒体、发送和调度。
- `feature/`：机器人业务规则，例如监听维护、管理员工作台、素材转发、任务执行。
- `extension/`：邮件通知、Webhook、SiverPanel 远程访问等外部增强。
- `templates/`：Web 管理面板模板与静态资源。
- `wxbot_logs/`：面板运行日志。
- `backups/`：一键备份产物。

## 使用与维护边界

- 微信主窗口需要保持可见，不要最小化。
- 这是个人自用 fork，默认优先当前目录结构和当前使用方式，不额外维护旧版迁移壳。
- 当前运行目录以 `data/`、`wxbot_logs/`、`backups/` 为准；跨设备继续使用时，优先复制这些真实数据目录。
- 公开同步代码前，不要提交 `data/config/`、`data/prompt/`、`data/accounts/`、`wxbot_logs/`、`backups/` 等本地私有数据。

## 迁移与打包

如果你只是把当前项目迁到新的主工作电脑，并且之后还会继续开发和运行，优先直接整目录复制。

如果你需要一份相对干净的独立运行包，可以执行：

```powershell
.\打包发布.ps1
```

默认产物是 `dist/WXBot_Pro.zip`。脚本会打包运行所需代码、`data/system_prompts/` 和内置 Python 3.12 runtime，不会把 `data/config/`、`data/prompt/`、`data/accounts/`、`wxbot_logs/`、`backups/`、`docs/`、`tests/`、本地 `venv/` 或 Git 元数据带进去。

## 常见问题

### 图片识别为什么有时看不到图？

当前图片回复已按结构化图片消息处理。支持视觉的回复接口会直接收图；不支持视觉的回复接口会先走辅助视觉，再交给主回复模型。

### 语音转文字是不是调用大模型？

不是。当前主要依赖微信自带的语音转文字能力。

### PowerShell 里看到中文乱码怎么办？

这通常是 Windows 控制台编码显示问题，不代表源码损坏。开发和排查时请按 UTF-8 读取文件。
